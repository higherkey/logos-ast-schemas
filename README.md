# Project Logos — Open AST Schema Registry

[![Deploy to GitHub Pages](https://github.com/higherkey/logos-ast-schemas/actions/workflows/deploy.yml/badge.svg)](https://github.com/higherkey/logos-ast-schemas/actions/workflows/deploy.yml)

This repository serves as the official, standalone public registry for **Project Logos Abstract Syntax Tree (AST) schemas**. 

It contains open-source, mathematically deterministic rules schemas for tabletop RPG systems (such as *Powered by the Apocalypse*, *Forged in the Dark*, and generic d20 SRDs).

## 🌐 Public Dashboard
View the live interactive catalog and inspect schemas directly at:
👉 **[https://higherkey.github.io/logos-ast-schemas](https://higherkey.github.io/logos-ast-schemas)**

## 📦 Directory Structure
- `index.html`, `styles.css`, `app.js` — Zero-dependency web dashboard for inspecting schemas and copying raw endpoint URLs.
- `schemas/index.json` — Central catalog manifest listing all published AST schemas, versions, and licenses.
- `schemas/*.json` — Individual AST schema definitions and node execution trees.
